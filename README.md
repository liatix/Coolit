# COOLIT landing page

Static landing page deployed automatically to Vercel from the `main` branch.

## Structure

- `index.html` - page markup, styling and behavior
- `assets/` - logo and event/equipment images

## Updating the site

1. Edit `index.html` for text, layout or styling changes.
2. Replace files in `assets/` for image changes while keeping the same filename, or update the matching path in `index.html`.
3. Commit changes to `main`.
4. Vercel automatically creates a new production deployment from the commit.
